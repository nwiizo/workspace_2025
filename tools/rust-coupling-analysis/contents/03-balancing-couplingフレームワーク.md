## Balancing Couplingフレームワーク

### 3つの測定軸

#### 1. Integration Strength（統合強度）
コンポーネント間で共有される知識の量。

```
Intrusive ━━━━ Functional ━━━━ Model ━━━━ Contract
(最強)                                     (最弱)
  1.0         0.75         0.5        0.25
```

#### 2. Distance（距離）
依存関係がどれだけ離れているか。

```
同じ関数 → 同じモジュール → 別モジュール → 別クレート
  0.0         0.25           0.5          1.0
```

#### 3. Volatility（変動性）
変更頻度から算出。Git履歴を解析。

```
Low (0-2回) → Medium (3-10回) → High (11回以上)
   0.0            0.5               1.0
```

### バランスの方程式

```
BALANCE = (STRENGTH XOR DISTANCE) OR NOT VOLATILITY
```

**理想的な状態:**
- 強い結合 × 近い距離 = 局所性が高い ✅
- 弱い結合 × 遠い距離 = 疎結合を保つ ✅

**避けるべき状態:**
- 強い結合 × 遠い距離 = 変更コストが高い ❌
- 弱い結合 × 近い距離 = 不要な抽象化 ⚠️
