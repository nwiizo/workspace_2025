## 実装したツールの実行例

上記の実装を元に、実際に動作するCLIツールを作成しました。

### インストールと実行

```bash
# プロジェクトをビルド
cargo build --release

# 基本的な使用方法（サマリー表示）
cargo run --release -- --summary
```

### 実行結果

実際にこのプロジェクト自体を分析した結果：

```
Analyzing project at './src'...
Analysis complete: 7 files, 7 modules

Coupling Analysis Summary:
  Files: 7
  Modules: 7
  Couplings: 0
```

### レポート生成

```bash
# 詳細レポートをMarkdown形式で生成
cargo run --release -- --output coupling-report.md
```
